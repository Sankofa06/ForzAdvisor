# Product Brief

ForzAdvisor is an unofficial iPhone tuning assistant for Forza players. The core job is to turn car performance details into a complete tune in Forza menu order, then make that tune easy to save, reopen, copy, and refine after driving.

## Primary Users

- Forza players tuning beside a console or PC.
- Players who prefer a fast offline setup.
- More advanced users who may opt into Anthropic API or on-device model assistance.

## Core Workflows

- Start a tune from camera, screenshot import, or manual entry.
- Confirm OCR values before generating any tune.
- Pick discipline: road, touge, drift, dirt/rally, cross-country, drag.
- Review tune sections in menu order.
- Copy individual values or the full tune.
- Save to garage and reopen later.
- Edit saved tune metadata and notes.
- Use guided refinement after a run.

## Product Direction

The app should stay fast, local-first, and trustworthy. Optional AI/provider paths should add polish without making the default tuning flow dependent on accounts, network, or paid keys.
