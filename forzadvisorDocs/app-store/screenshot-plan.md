# ForzAdvisor screenshot specification

The canonical specification is [AppStore/screenshots-spec.md](../../AppStore/screenshots-spec.md). It defines real simulator capture, deterministic demonstration data, file order, image validation, provenance, and visual review.

Use [AppStore/marketing/README.md](../../AppStore/marketing/README.md) for capture and marketing-package guidance, and [AppStore/release-config.json](../../AppStore/release-config.json) for the upload order.

The former drawn-mockup generator is retired. Do not use historical generated images as current app captures.
