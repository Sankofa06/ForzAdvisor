## Description

Your car. Your inputs. A clearer next setup.

ForzAdvisor is an unofficial iPhone racing-game companion that puts the facts you supply into an organized tuning workflow.

START WITH YOUR CAR
Photograph a performance screen, import your own screenshot, or enter the details manually. Check and edit the values before continuing. There is no bundled car roster or reviewed stock catalog.

CHOOSE YOUR DRIVE STYLE
Choose road, drift, drag, dirt/rally, cross-country, or touge. Keep your car details and intended discipline together before generation.

KNOW WHAT THE OUTPUT MEANS
FH5 produces a local build plan with no numeric tuning settings. FH6 uses experimental tuning guidance: numeric settings are shown only when the applicable capability, range, and evidence checks permit them. Unsupported or unverified values are withheld. A generated result does not establish in-game performance or universal tuning coverage.

KEEP YOUR GARAGE USEFUL
Save setups locally, search cars, styles, and notes, filter by discipline, and sort by car name or recent updates. Copy eligible settings in game-menu order or copy a build plan. Where verified settings are eligible, Guided Refinement lets you preview changes before applying them, with Discard and Undo.

CHOOSE HOW YOU GENERATE
Offline formulas are the default. Photo and screenshot reading runs on device. Optional on-device model assistance depends on device availability. Optional API mode uses your own Anthropic API key; review the provider and privacy details before starting. FH5 remains local and plan-only in every mode.

ForzAdvisor is not affiliated with, endorsed by, or sponsored by Microsoft, Xbox, Turn 10 Studios, Playground Games, or the Forza franchise.

## App Review Notes

No login or API key is required for the default offline workflow. This candidate has no bundled car roster. New Tune offers Take Photo, Import Screenshot, and Enter Manually.

Suggested review path:

1. Launch the app, tap New Tune, then Enter Manually.
2. Choose FH5 and enter valid car and performance details. Continue, choose Road, and generate a local build plan. Confirm it contains no numeric tune settings.
3. Save the plan. Search for it in Garage, filter by discipline, and try Recently updated and Car name sorting.
4. Start another manual entry with FH6. Confirm that missing capability, range, or verification evidence leaves affected numeric settings withheld. A successful generation does not promise a complete numeric tune.
5. If genuine matching evidence makes settings eligible, review copy and Guided Refinement preview, Apply, Discard, and Undo. Do not create fictional observations to unlock these actions.
6. Optionally import your own performance-screen screenshot. Review and correct detected values before continuing. Camera permission is requested only when Take Photo is chosen; import uses the system picker.

Optional testing and research tools are separate from ordinary setup creation. Marketing screenshots use seeded demonstration garage entries only in the Debug simulator capture flow. Production starts with user-owned data. These presentation fixtures are not validation evidence. Optional on-device and user-key API modes are selected in Settings; neither enables numeric FH5 output.
